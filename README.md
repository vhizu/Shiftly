# Shiftly 1.4.1 — Operator Edition 💜

Полный проект SwiftUI для iPhone (iOS 17+) с исходниками, ассетами маскота, Live Activity, Dynamic Island, домашним виджетом и GitHub Actions для сборки unsigned IPA.

## Что нового
Автоматический график смен; напоминания за час и 15 минут; круговой таймер; кнопка завершения перекура в Live Activity; домашний виджет; статистика; редактирование смен/перерывов; журнал оборудования; экспорт CSV; резервные копии JSON.

## Сборка
Скопируйте содержимое папки проекта в корень GitHub репозитория, закоммитьте и запустите workflow `Build Shiftly 1.4 IPA` в Actions. GitHub Actions использует macOS, XcodeGen и xcodebuild.

## Важное ограничение
Нужна подпись с App Group `group.com.shiftly.app` для взаимодействия приложения и расширений. Не все варианты sideload-подписи через GBox поддерживают App Groups. Синтаксис Swift проверен, но компиляция Xcode и работа на iPhone не подтверждены. Подробнее в BUILD_STATUS.md.

## 1.4.2
В «История» → «Исправить смену и перекуры» добавлена кнопка «Добавить забытый перекур». Выбираются дата и время начала/окончания; проверяются границы смены, будущее время и пересечения с существующими перерывами. Запись учитывается в лимите, статистике и резервной копии.

## 1.4.3 — Автоматический старт смены
При открытии приложения сверяем график и восстанавливаем текущую смену с планового начала (08:00 или 20:00), в том числе после переустановки и для ночной смены через полночь. На главном экране отображается фактическое начало учётной смены. Автоматический учёт можно отключить в настройках.


## Shiftly 1.5.0 (исходники)

На основе установленной и проверенной пользователем версии 1.4.3. Изменения:

- 15-минутный отсчёт отдельно от общего лимита смены (по умолчанию 120 минут).
- Живая реакция операторши: меняющиеся подписи/состояния в зависимости от оставшегося времени (иллюстрации существующие, нового Live2D-рига нет).
- Быстрый запуск перекура из интерактивного виджета iOS 17+ (один тап; открывается приложение для запуска Live Activity).
- Аналитика дневных и ночных смен, среднее и число перекуров, соблюдение лимитов.
- Компактный главный экран, настройка запоминается.
- Уведомления за 5/2/1 минуту и по истечении лимита одного перекура, плюс общий лимит.
- Проверка границ и пересечений при правке перекуров; удаление ошибочной записи, добавление пропущенной.
- Автоснимки JSON в локальной папке Documents/ShiftlyBackups, последняя копия обновляется при сохранении, история до 20 снимков. **Удаление приложения удалит локальные снимки** — нужно заранее экспортировать копию через «Настройки → Экспорт и восстановление» в iCloud Drive/Файлы.
- 5 вкладок вместо системной вкладки More, русская дата и локаль.
- Прогноз до конца смены и видимый остаток общего лимита.

**Сборка:** `.github/workflows/build.yml` генерирует XcodeGen проект, выполняет `xcodebuild clean build` и проверяет оба встроенных расширения. Сборка unsigned; для установки подпишите IPA через GBox, включая все расширения. Соответствие интерфейса и функции кнопок подтверждаются только после теста на устройстве.
