# Shiftly — iOS

Исходный проект iPhone-приложения Shiftly, сборка через XcodeGen и GitHub Actions.

## 1.11.0 — этап 1 (маскот / главная)

- Добавлены 5 подготовленных PNG-маскотов (работа, кофе, обед, выходной, успех) и `MascotScene.swift` для выбора состояния.
- Маскот больше не скрывает лицо за таймером: у главной появился отдельный визуальный отступ, фон плавно растворяется.
- Нажатие на фон маскота или подпись меняет контекстную реплику.
- Убраны кнопка и экран «Фокус», быстрые кнопки выровнены по двум колонкам.
- Исправления календаря, палитры, настроек и рабочих заметок входят в **следующие этапы 1.11**, здесь они ещё не реализованы.
- Для ночного состояния используется чистая базовая поза: отдельный ночной рисунок пока содержит грязный фон. Рисунок заметок тоже пока не включён в UI.

### Сборка

Пуш ветки `dev/1.11` запускает GitHub Actions (`.github/workflows/build.yml`), где собирается unsigned IPA. Для разработки на Windows удобнее GitHub Desktop + VS Code; iOS-компиляция выполняется только на macOS runner.

**До первой тестовой установки:** экспортируйте JSON-бэкап текущей Shiftly в «Файлы». История и модель данных от 1.10.0 не менялись.
