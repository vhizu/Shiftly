# Shiftly 1.10.0 — Smart Home & Lunch 💜

Полный исходный проект iPhone-приложения Shiftly, iOS 17+, с native Liquid Glass при iOS 26+ и сборке Xcode 26.3.

**Что нового:** обед 30 минут внутри общего лимита отдыха, умная главная, большой маскот с бесшовным градиентом, портретная ориентация, 144 фразы, отмена последних действий, тактильная отдача, энергосбережение, расширенная история и защита локального JSON. Подробности: `CHANGELOG_1.10.0.md`. Проверки: `TEST_CHECKLIST_1.10.0.md`.

## Обновление через Working Copy

1. Экспортируй текущую резервную копию JSON в iCloud Drive или «Файлы» за пределы папки приложения.
2. Открой `vhizu/Shiftly` в Working Copy и замени корневые файлы содержимым папки `Shiftly-1.10.0` из архива (в том числе `Shared`, `Shiftly`, `ShiftlyLive`, `ShiftlyHomeWidget`, `project.yml`).
3. Скопируй `.github/workflows/build.yml`; если скрытая папка не видна, используй **идентичный** файл `Workflow/build.yml` и помести его в `.github/workflows/build.yml`.
4. Commit → Push. В GitHub Actions найди `Build Shiftly 1.10.0 IPA`. Скачай артефакт `Shiftly-1.10.0-unsigned-IPA` и подпиши GBox, сохранив основной Bundle ID и оба расширения.
5. Не удаляй установленную рабочую версию до успешной проверки новой и отдельного экспорта JSON.

**Статус:** проверка исходников и совместимости JSON пройдена; GitHub/iOS-компиляция и проверка на телефоне ещё не выполнены.
