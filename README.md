# Shiftly 1.6.0 — Operator Edition 💜

Полный исходный проект для iPhone (iOS 17+). Исходная работающая база: Shiftly 1.4.3; последнее обновление — 1.5.1 с системным обратным отсчётом Live Activity. Существующие данные `shiftly.v1.data` сохраняются (модель `ShiftData` совместима с предыдущими JSON-копиями).

## Что нового в 1.6.0

- **Центр перекуров** прямо с главной: добавить завершённый забытый перекур за 5/10/15 минут или с ручными датами; запустить уже идущий перекур с началом 5/10/15/20/30 минут назад. Проверяется смена, границы дат и пересечения записей.
- **Умный прогноз отдыха**: остаток общего лимита, число полных перекуров и ориентировочный интервал до конца смены. Это подсказка, не рекомендация нарушать правила работодателя.
- **Следующая смена**: отдельный экран с обратным отсчётом до ближайшей обычной или дополнительной смены; цикл Д Д В Н Н В В В, 4 ноября 2026 — первая ночь.
- **Реакции операторши**: ранее добавленные изображения, подписи и предупреждения переключаются в зависимости от длительности перекура. Новых изображений или Live2D-рига в версии нет.
- **Отчёт после смены**: поработал/отдыхал, число и максимум перекуров, остаток общего лимита; переход из истории и из домашнего экрана после смены; поделиться текстом.
- **Ночной неон** на главном во время ночных смен (переключатель в настройках); компактный режим из 1.5 сохранён.
- **Прогноз зарплаты**: расчёт по текущим данным + будущие 12-часовые смены до конца месяца с заданными ставками и коэффициентами. Условная оценка без вычета будущих перекуров и без налогов.
- **Dynamic Island**: раскрытый вариант использует маленький проверенный `IslandIconBreak` вместо большого PNG, который показывался серым квадратом. Системные таймеры из 1.5.1 оставлены.

## Сохранённые функции

Смена по графику; перекур 15 минут и отдельный общий лимит; живая активность и кнопка «Вернулся к работе»; виджет с запуском перекура; напоминания; история/редактирование; статистика; зарплата; календарь подработок; заметки оператора TNA/Yamato; локальные автокопии и ручной экспорт/импорт JSON и CSV.

## Установка / сборка

1. В Working Copy открой `vhizu/Shiftly` и замени содержимое корня файлами **внутри** папки `Shiftly-1.6.0/`.
2. Скопируй скрытую папку `.github` в корень репозитория: именно `.github/workflows/build.yml` запускает сборку. Для проверки с iPhone доступен видимый дубль `Workflow/build.yml`.
3. Commit → Push (например: `feat: Shiftly 1.6 — break hub, night neon and shift forecasts`).
4. Открой GitHub Actions → `Build Shiftly 1.6.0 IPA`. Подпиши **unsigned IPA** в GBox сертификатом, поддерживающим основное приложение и оба расширения.
5. Перед удалением/переустановкой Shiftly экспортируй JSON в «Файлы» или iCloud Drive: локальные резервные копии удаляются вместе с приложением.

**Статус:** Swift-синтаксис и архив проверены. Полная сборка Xcode, подпись GBox и тест на реальном iPhone не выполнялись в рамках создания этого ZIP. Если GitHub Actions выдаст ошибку, используй его лог для диагностики.

## Shiftly 1.7.0 — Центр резервных копий

Вкладка «Ещё» → «Резервные копии»: создание ручного JSON-снимка, экспорт в «Файлы»/iCloud Drive, просмотр всех локальных копий с датами, предпросмотр выбранного JSON (смены, перекуры, заметки), защитное сохранение данных перед восстановлением. JSON из системного окна выбирается как generic item и проверяется после загрузки. На главном экране кнопка «Забытый перекур» сразу открывает редактор. Прежние Live Activity, Dynamic Island, виджеты, график, зарплата и оформление сохранены.

**Важно:** локальные снимки не являются iCloud Backup. Для защиты от удаления программы экспортируйте JSON в отдельное место.


## Shiftly 1.9.0 — Glass Overhaul

Полный редизайн с компактным меню и прозрачными карточками. На iOS 26+ интерактивные поверхности используют native Liquid Glass (при компиляции актуальным Xcode); на более ранних iOS применяется системный материал. Маскот, активные перекуры, Live Activity и JSON-модель сохранены.

### JSON резервные копии

Открой «Ещё → Резервные копии». Выбери файл JSON из «Файлов» (системный провайдер откроет копию файла), либо выбери папку и нажми «Обновить список файлов». Если файловый провайдер не позволяет выбрать файл, открой JSON как текст, скопируй его целиком и воспользуйся «Вставить текст JSON из буфера». Перед восстановлением увидишь содержимое, подтверждение и автоматическую страховочную копию. Приложение не может сканировать произвольные папки iCloud без предоставленного доступа.

Файл `.github/workflows/build.yml` скрыт в приложении «Файлы» iPhone; видимая копия — `Workflow/build.yml`.
