# Shiftly 1.6.1 — восстановление резервных копий

- Исправлен импорт из приложения «Файлы»: системный выборщик принимает любые файловые типы вместо слишком строгого фильтра `.json`.
- После выбора файл проверяется JSONDecoder как `ShiftData`, чтобы другие файлы не записали мусор вместо истории.
- При доступе к выбранному файлу используется security-scoped URL; неуспех получения scope не блокирует чтение уже доступного файла.
- Перед заменой истории показывается подтверждение и создаётся принудительный локальный JSON-снимок старых данных.
- В случае ошибки чтения/декодирования старые данные не изменяются, показывается сообщение.
- Обновлены `project.yml` и оба workflow на 1.6.1. Все остальные функции 1.6 сохранены.

Проверка на iPhone: экспортируй JSON через настройки → экспорт. Затем настройки → восстановление, открой файл из «Файлов»/iCloud Drive и подтверди. Проверь количество смен и перекуров. Сохрани оригинальный бэкап вне приложения до проверки.
