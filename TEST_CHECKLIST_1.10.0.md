# Shiftly 1.10.0 — контрольный список после GitHub Actions

## Выпуск
- [ ] GitHub Actions: Xcode 26.3, JSON/model test успешен, IPA приложен к артефактам.
- [ ] IPA содержит основной app + два .appex; идентификаторы com.shiftly.app, .live, .home не изменились.
- [ ] Информация о приложении: 1.10.0, build 21; iPhone ориентации только Portrait.
- [ ] Экспортировать действующий JSON **до** удаления или переустановки приложения.

## Главная, оформление
- [ ] Поворот iPhone не меняет ориентацию UI.
- [ ] На дневной/ночной смене нет прямоугольной границы у ног операторши.
- [ ] Настоящий Liquid Glass остался на таймере и кнопках.
- [ ] Переключателя компактной главной больше нет.
- [ ] В работе кольцо показывает время до конца смены, без дублирования справа.
- [ ] Касание реплики меняет слова; в настройках работают редко/обычно/часто.
- [ ] Reduce Motion и Low Power Mode останавливают фоновую анимацию.

## Обед и лимит
- [ ] На работающей смене нажать «Обед · 30 мин» → отсчёт 30:00.
- [ ] Во время обеда кнопка завершает его, новый перекур запустить нельзя.
- [ ] Dynamic Island в compact и expanded показывает обед и живой таймер.
- [ ] Live Activity на экране блокировки показывает «Обед» и работающую кнопку «Завершить обед».
- [ ] При разрешённых уведомлениях приходят предупреждения за 5, 2 и 1 минуты.
- [ ] 30 минут обеда + 10 минут перекура уменьшают общий лимит 120 до 80 минут.
- [ ] При лимите 150 расчёт тоже правильный.
- [ ] Отмена запуска/завершения обеда до 20 секунд восстанавливает корректный отсчёт.

## Данные и история
- [ ] В «Забытый перерыв» можно выбрать обед и внести 30 минут в прошлое.
- [ ] В истории обед можно отредактировать / удалить, перекуры не исчезают.
- [ ] Статистика различает число перекуров и обедов.
- [ ] Сводка законченной смены в главной показывает оба типа.
- [ ] Старый JSON (Shiftly <= 1.9.2) импортируется и прежние перерывы становятся перекурами.
- [ ] Экспорт и восстановление нового JSON сохраняет поле вида обеда.
- [ ] После убийства приложения/перезагрузки история и таймеры восстановились.
- [ ] После автоматически завершённой 12-часовой смены не тянется бесконечно активный перерыв.
- [ ] В конце дня: «Журнал линии», зарплата, подработки и график работают как раньше.
