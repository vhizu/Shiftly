# Shiftly 1.7.0

- Центр резервных копий со списком снимков, датой/размером и экспортом через Share Sheet.
- Просмотр JSON перед восстановлением: смены, перекуры, заметки, лимиты.
- Проверка данных и отдельная страховочная копия перед заменой истории.
- Возможность создать ручной JSON-снимок и отправить в «Файлы»/iCloud Drive.
- Быстрый переход в редактор забытого перекура с главной панели.
- Сохранены Live Activity, системный таймер Dynamic Island, история и остальные функции 1.6.1.

Нужно проверить: компиляцию Xcode в GitHub Actions; импорт JSON на iPhone; экспорт/восстановление без потери истории.
