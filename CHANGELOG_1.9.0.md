# Shiftly 1.9.0 — Glass Overhaul

- Сохранён маскот; уменьшена высота шапки главного экрана, чтобы таймер и кнопки были видны быстрее.
- Реально прозрачные информационные карточки, тонкие светлые контуры, нативные iOS 26 Liquid Glass элементы управления (fallback для iOS 17–25).
- «Ещё» заменено на компактные ровные строки; устранены пустые гигантские плитки и дублирующиеся переходы.
- Главная: одна основная кнопка текущего перекура, вспомогательные «Забытый перекур» и «Фокус».
- Статистика, график, зарплата и история используют согласованную геометрию, отступы и контрастные заголовки.
- Убраны лишние вложенные NavigationStack и двойные кнопки «Закрыть» на переходах.
- Dynamic Island и экран блокировки получили согласованный фиолетово-голубой стиль, сохранён системный живой таймер, кнопка возврата к работе и проверенный мини-маскот вместо большого изображения с серым квадратом.
- Центр резервных копий: выбор JSON через широкий document picker (copy mode), сканирование выбранной папки, реальная кнопка обновления, ручные снимки, предпросмотр, страховочная копия перед восстановлением.
- Резервный импорт из буфера обмена для провайдеров «Файлов», не разрешающих выбрать JSON.
- Внутренняя структура ShiftData и ключи хранилища остались прежними; данные старых JSON не менялись.
- GitHub Actions clean-build и проверка обоих расширений; видимая копия workflow в Workflow/build.yml.

## Проверка

Swift-файлы проверены синтаксическим парсером локально. Полная компиляция Xcode, подписание в GBox, поведение File Provider и визуальная проверка на iPhone должны быть протестированы после GitHub Actions.
