# Shiftly 1.10.0 — Smart Home, обед и разговорчивая операторша 💜

## Главное

- Portrait-only для основного приложения iPhone; horizontal layout больше не используется.
- Liquid Glass из 1.9.2 сохранён (Xcode 26.3 в GitHub Actions).
- Бесшовный фон маскота с плавным исчезновением у ног; устранён фиксированный тёмный слой 78% высоты.
- Удалён неработающий переключатель компактной главной панели и настройка для него.
- Автоматическая главная: работа / перекур / обед / выходной, без двойного отображения времени до конца смены.
- Обед 30 мин — отдельная кнопка и тип перерыва, **входит в общий лимит** (120 / 150 мин, зависит от лимита смены).
- Одновременно два перерыва запустить невозможно. Перекур по умолчанию 15 мин и настраивается, обед 30 мин фиксирован.
- Обед имеет отдельный отсчёт в Live Activity и Dynamic Island, уведомления за 5/2/1 минуту, подпись «Завершить обед».
- История, редактирование, забытый обед, отчёты и статистика различают обеды и перекуры.
- Отмена последнего запуска/завершения перерыва на главной в течение 20 секунд при корректном состоянии.
- Автоматический локальный latest JSON при изменениях, атомарная запись, периодические снимки и чтение последней резервной копии при повреждении основных сохранений.
- 144 офлайн-реплики маскота: день, ночь, середина/конец смены, обед, перекур, предупреждения, выходные и редкие фразы. Частота настраивается, реплику можно обновить касанием.
- Тактильная отдача с переключателем в настройках.
- Адаптивный цвет подсветки по дневной/ночной смене; фоновые анимации останавливаются при энергосбережении и Reduce Motion, главный экран обновляется реже при Low Power Mode.
- Сводка последней законченной смены одной карточкой на главной и переход к полному отчёту.
- Фоновая/автоматическая синхронизация при смене состояния приложения и периодическая проверка завершения смены при работе в открытом приложении.

## Совместимость

- `ShiftData` и App Group `group.com.shiftly.app` не переименованы.
- В новой записи `BreakSession.kind` — опциональное поле. Отсутствующее поле из старых JSON означает `.smoke`. Старые бэкапы можно импортировать как раньше.
- `ShiftlyLive` и `ShiftlyHomeWidget` сохраняют прежние bundle identifiers, кнопку возврата и иконки.
- Перезапись IPA с новой версией не должна требовать стирания данных, если используется тот же сертификат/Bundle ID; до переустановки всё равно экспортируйте JSON.

## Сборка

1. Скопировать **содержимое** папки `Shiftly-1.10.0/` в корень GitHub-репозитория `vhizu/Shiftly` через Working Copy.
2. Проверить наличие скрытого `.github/workflows/build.yml` (видимая копия `Workflow/build.yml`).
3. Commit → Push; GitHub Actions создаст `Shiftly-1.10.0-unsigned.ipa`.
4. Подписать IPA через GBox и проверить на iPhone 16 Pro. Оставить прежнюю рабочую установку до экспорта JSON.

**Статус:** Swift-синтаксис, исходники, старый/новый JSON и архивация проверены локально. Полная iOS-сборка, работа Live Activity, визуальный интерфейс и GBox **не тестировались** в этой среде.
